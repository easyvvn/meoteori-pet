머털이 (Codex 데스크톱 펫)

Codex가 일하는 중인지, 확인이 필요한지, 끝났는지를
머털이와 카드로 알려 줍니다.

설치
1. 터미널 앱을 엽니다.
2. zsh 를 치고 한 칸 띄운 뒤, 이 폴더의 '설치.command'를 터미널 창에 끌어다 놓고 엔터.
   (더블클릭은 '확인되지 않은 개발자' 경고로 막힐 수 있어서 이 방법이 확실합니다.)
3. '끝.'이 나오면 앱 설치는 완료.
4. Codex에서 훅을 한 번 믿어 줘야 합니다. 이걸 안 하면 머털이가 반응하지 않아요.
   터미널에서 codex 를 열고 /hooks 를 입력 → 머털이 훅(meoteori-inbox)을 신뢰(trust).
5. Codex 앱을 쓰면 앱을 Cmd+Q 로 완전히 끄고 다시 엽니다. (앱은 켜질 때만 훅 설정을 읽음)
6. 새로 여는 Codex 채팅부터 머털이가 반응합니다.

설치가 하는 일
- 앱을 ~/Applications/Meoteori.app 에 복사
- ~/.codex/hooks.json 에 훅 추가 (고치기 전 백업 남김, 기존 훅은 그대로)
- 로그인할 때 자동으로 켜지게 등록

되는 곳
- Codex (터미널, Codex를 쓰는 앱)
- ChatGPT 일반 대화창은 안 됩니다 (상태를 밖으로 알려 주지 않음)
- Codex 권한이 '읽기 전용(read-only)'이면 반응하지 않습니다. 기본 · 전체 액세스는 됩니다.
  (Codex는 훅도 자기 샌드박스 안에서 돌려서, 읽기 전용이면 신호 파일을 못 씀)

쓰는 법
- 머털이 클릭 = 하트, 카드 클릭 = Codex 앱 열기
- 끌어서 화면 아무 데나 놓기 (놓은 자리를 기억함)
- 메뉴 막대 발바닥 아이콘 = 숨기기 · 산책 끄기 · 미리보기 · 종료

Claude Code도 같이 쓰면 Claude용 묶음의 '설치.command'도 돌리면 됩니다. 앱은 하나라 둘 다 받아요.

다시 설치 · 업데이트 = 새 묶음의 '설치.command'를 다시 실행 (여러 번 돌려도 안전)
자동 실행 해제 = 터미널에서
  launchctl bootout gui/$(id -u)/kr.lizzy.meoteori && rm ~/Library/LaunchAgents/kr.lizzy.meoteori.plist

필요: macOS 13 이상. 애플 칩 · 인텔 둘 다 됨.
