머털이 (Claude Code 데스크톱 펫)

Claude Code가 일하는 중인지, 확인이 필요한지, 끝났는지를
머털이와 카드로 알려 줍니다.

설치
1. 터미널 앱을 엽니다.
2. zsh 를 치고 한 칸 띄운 뒤, 이 폴더의 '설치.command'를 터미널 창에 끌어다 놓고 엔터.
   (더블클릭은 '확인되지 않은 개발자' 경고로 막힐 수 있어서 이 방법이 확실합니다.)
3. '끝.'이 나오면 완료. 창은 닫아도 됩니다.
4. 새로 여는 Claude Code 세션부터 머털이가 반응합니다.

설치가 하는 일
- 앱을 ~/Applications/Meoteori.app 에 복사
- ~/.claude/settings.json 에 훅 추가 (고치기 전 백업 남김, 기존 훅은 그대로)
- 로그인할 때 자동으로 켜지게 등록

쓰는 법
- 머털이 클릭 = 하트, 카드 클릭 = 그 세션 열기
- 끌어서 화면 아무 데나 놓기 (놓은 자리를 기억함)
- 메뉴 막대 발바닥 아이콘 = 숨기기 · 산책 끄기 · 미리보기 · 종료

다시 설치 · 업데이트 = 새 묶음의 '설치.command'를 다시 실행 (여러 번 돌려도 안전)
자동 실행 해제 = 터미널에서
  launchctl bootout gui/$(id -u)/kr.lizzy.meoteori && rm ~/Library/LaunchAgents/kr.lizzy.meoteori.plist

필요: macOS 13 이상. 애플 칩 · 인텔 둘 다 됨.
